Topic drill-down — division with remainders

The missed Questions are generated content, so they are PAPER role (square) and set in Literata; everything around them stays Source Sans 3. Grade states here use the same four non-colour carriers and the same four labels as the Student Mode results screen — icon frame shape, glyph, the literal words, and the row left-rule texture — so a row means the same thing in both rooms. Unanswered is neutral, not warning: warning is the Weak Area hue on this very screen, and a row that showed both would have used one colour for two unrelated meanings at once. The weighted regenerate control sits with the evidence that justifies it and states its cost in practice tests before it fires, because that is the unit the Generation Allowance is counted in.
