Type pairings — round 1

Five serif + sans duos for n-test-reviewer. In every pairing the serif carries content a student reads carefully (question stem, fractions, explanations — including inside Parent View when a generated question is shown) and the sans carries chrome (nav, buttons, labels, dashboard tables, admin).

One shared type scale runs across both surfaces; the ramp is identical in all five pairings so the only variable being judged here is the typefaces. Density between Student and Parent is carried by spacing, never by type size.

  • Every family passed the tabular-numeral hard filter — verified by downloading the real Google Fonts woff2 and inspecting GSUB for tnum plus hmtx digit advance widths. Method and raw results are in the <style> comment at the top of this file.
  • font-variant-numeric: tabular-nums is applied only to the countdown timer, the Mastery % column, scores (11/15) and consumption counts. Everything else stays proportional.
  • All specimen text is real product content. Correct/incorrect states always pair colour + icon + text label.
Pairing 01 · reading-first

Literata + Source Sans 3

Drawn for the job. Literata was commissioned for long-form reading on screens (Google Play Books) and is widely used in school reading products — generous x-height, sturdy serifs, low contrast, forgiving at small sizes and on a mid-quality tablet panel. Source Sans 3 is deliberately quiet chrome that never competes with the question.

Literata: tabular numerals ✓ — real tnum feature (default figures proportional, so tnum must be switched on) Source Sans 3: tabular numerals ✓ — digits are monowidth by default (no feature needed) Fractions: Literata has native frac

Light · explanation
✕ Incorrect — your answer: 15.58 ✓ Correct answer: 15 boxes, 7 left over

There are 187 workbooks and each box holds 12. Twelve goes into 187 fifteen times, because 15 × 12 = 180. Those 180 workbooks fill 15 boxes completely and leave 7 behind.

The 7 remaining workbooks are not enough to fill another box, so they stay as a remainder rather than turning into part of a box. When a question asks how many boxes are completely full, the leftover is reported separately: 15 boxes, with 7 workbooks left over.

Pairing 02 · neutral-modern

Source Serif 4 + IBM Plex Sans

Institutional calm. Source Serif is a low-drama transitional serif that reads as a document rather than a storybook; IBM Plex Sans is slightly narrow and engineered, with unmistakable digits. Together they read serious and school-issued — the least "kids' product" of the five, which is either the point or the problem.

Pairing 03 · accessibility-forward

Charis SIL + Atkinson Hyperlegible Next

Legibility as the brief. Charis is SIL's literacy typeface — heavy slab-like serifs, very large x-height, drawn to survive poor rendering and low-quality print in reading programmes. Atkinson Hyperlegible Next was commissioned by the Braille Institute to maximise letterform distinctiveness for low-vision readers. The most defensible pairing on paper; also the least stylish.

Charis SIL: tabular numerals ✓ — all ten digits share one 1153/2048 advance by default Atkinson Hyperlegible Next: tabular numerals ✓ — real tnum feature (default figures proportional) Fractions: ⚠ no native frac in either family — must be composed in CSS / a component

Pairing 04 · editorial

Newsreader + Inter

Magazine voice. Newsreader carries higher stroke contrast and sharper, more literary detail than the others — question text feels authored rather than generated, which is a useful signal for an AI-generated product. Inter behind it is the most neutral UI sans in wide use, so all the personality stays on the content side.

Pairing 05 · most character

Petrona + Work Sans

The warm one. Petrona has a humanist, slightly irregular pen quality — question text reads like something a person wrote for a child rather than a system output. Work Sans is friendly and a shade geometric. Highest personality of the five and the closest to the gamified line we are avoiding; it earns its place only if the chrome stays sober.

Supporting values in the same palette: secondary text 6.50:1 light / 7.66:1 dark; Student primary 5.96:1 light / 8.14:1 dark; Parent primary 6.57:1 light / 7.64:1 dark; error 6.54 / 7.72; success 6.49 / 8.92; warning 5.93 / 8.56. Status is never carried by colour alone — every state above pairs a colour, an icon and a text label.
